# Incident Triage Dashboard

A tutorial-owned demonstration repository for an operations incident-triage dashboard. The project is rebuilt from a product contract, a prototype handoff, visual constraints, acceptance scenarios, and browser E2E evidence.

## Delivery stages

1. Product analysis
2. Wireframe
3. UI design and design inspiration
4. High-fidelity prototype
5. Acceptance contract
6. Code development
7. E2E testing
8. Deliverable

The `handoff/` directory records the artifacts that connect those stages.
