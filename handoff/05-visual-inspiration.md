# Visual Inspiration Research

## Research boundary

The research supports an original Incident Triage Dashboard design. It identifies transferable principles, not layouts or assets to reproduce. The approved [product contract](01-product-contract.md) remains the authority for behavior and permissions.

## Sources

### Incident Response Dashboard UI Design

- Author: Shadhin Ahmed
- Source: [Dribbble](https://dribbble.com/shots/25884666-Incident-Response-Dashboard-UI-Design)
- Useful principles:
  - Keep the incident queue visually dominant and minimize decorative competition.
  - Use restrained signal color so urgent states remain recognizable in dense operational data.
  - Group filters, queue context, and detail inspection into one continuous workspace.
- Do not copy:
  - The exact navigation, card arrangement, typography, iconography, branding, color values, or dashboard composition.

### Cyber Security Investigation & AI Analytics Dashboard

- Authors: M. Mostafizur, M. Nazmul, and M. Shafayet
- Source: [Behance](https://www.behance.net/gallery/253696339/Cyber-Security-Investigation-AI-Analytics-Dashboard)
- Useful principles:
  - Separate persistent operational context from transient alerts and recovery actions.
  - Maintain a predictable hierarchy across dense tables, side panels, and responsive layouts.
  - Reserve higher-contrast treatments for actions and conditions that require immediate response.
- Do not copy:
  - The investigation workflow, AI features, chart combinations, branded assets, illustrations, exact layout, or visual system.

## Evaluation criteria

| Criterion | Design implication |
| --- | --- |
| Information density | Preserve rapid scanning without compressing rows below a comfortable operational rhythm. |
| 24×7 use | Avoid high-glare surfaces and excessive saturated color during long shifts. |
| State recognition | Encode severity and status with text and shape or icon, never hue alone. |
| Accessibility | Target WCAG 2.2 AA, visible focus, keyboard operation, and persistent labels. |
| Maintenance cost | Prefer one type family, a compact semantic token set, and reusable state patterns. |

## Synthesis supplied to Figma Design Agent

The Agent received the product contract, the editable Make reference frames, the principles above, and explicit anti-copy constraints. It was instructed to discuss three original directions before writing to the canvas:

1. Operational Light.
2. Midnight Command.
3. Calm Control.

The visual design was generated and iterated by the Figma Design Agent in Figma's browser UI. Codex did not use Figma MCP drawing or generation capabilities.
